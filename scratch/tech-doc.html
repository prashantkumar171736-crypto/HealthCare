§ 1 🏗️

Project Overview & Technology Stack

Rog Care Hindi (deployed as HealthEdu in the codebase) is a free, peer-reviewed healthcare education platform targeting Indian users in Hindi and English. It allows visitors to read about 100+ diseases, browse health tips, donate, and interact via a community forum — all without any paywalls or advertisements.

Live URL: https://rogcarehindi.vercel.app  |  Deployment: Vercel  |  DB: MongoDB Atlas

Technology Stack

LayerTechnologyVersionPurpose
FrameworkNext.js16.2.9Full-stack SSR/SSG React framework
UI LibraryReact19.2.4Component-based UI rendering
LanguageTypeScript5.xType-safe development
DatabaseMongoDB7.3.0NoSQL document store for all content
StylingTailwind CSSv4Utility-first CSS framework
FontsGoogle Fonts (Geist, Noto)—Multi-script typography
HostingVercel—Edge deployment & CDN
AnalyticsGoogle Analytics 4—User behavior tracking
SEONext.js Metadata API + Schema.org—Search engine optimization

Key Functional Areas

🌐 Public Education Platform

Disease directory (100+ articles), 15 categories, health library, tips, FAQ, About.

💰 Donation System

UPI/QR donation flow with configurable amounts, dynamic QR generation, modal confirmation.

🌏 Multi-Language Support

Auto-detection of 20+ scripts (Hindi, Arabic, Bengali, Tamil etc.) with automatic Google Translate integration.

🛡️ Admin Control Panel

Secure admin with analytics dashboard, content editor, donation config, comments moderation, appearance theming.

Wraps the entire app in src/context/LanguageContext.tsx. Provides: current language code, setLangByCode(), setLangFromText(), resetToEnglish(), isTranslating boolean. Language preference is persisted to localStorage and applied to <html lang> and <html dir>.

Disease A-Z Directory

File: src/app/diseases/page.tsx — Server Component. Route: /diseases. Accepts query params: ?search= and ?letter=. Includes BreadcrumbList JSON-LD.

Page Elements

Page Heading "Disease A-Z Directory" with a description paragraph.
SearchBar Same shared component with custom placeholder: "Type to search... (e.g. Cancer, Dengue, Anemia)"
Alphabet Filter Bar A row of 27 buttons: "All" + A–Z. Active letter highlighted in primary color. Clicking sets ?letter=X URL param and filters diseases by first letter.
Disease Grid (3-column) Each card shows: category badges (colored pills), disease name, 160-char overview snippet, and a "Read Article" button → navigates to /diseases/[slug].
Empty State Shown when no diseases match — displays 🔍 emoji, "No diseases found" heading, and help text.
Search Results Header When ?search= is set, shows "Search Results for '{query}' (N found)".

Search Relevance Algorithm

Scoring: +100 for exact query in name, +50 in overview, +15 per word in name, +8 per category match, +5 per word in overview. Results sorted by score descending. Both diseases and blog posts are merged in results.

  • "🌐 [Language] detected" badge when non-English is typed
  • Click-outside closes dropdown
Tracker — src/components/Tracker.tsx

Invisible component. On each route change, POSTs to /api/track with: current path, referrer, user agent. Server enriches with IP geolocation (country, region, city) and stores in MongoDB tracker collection.

PageTranslator — src/components/PageTranslator.tsx

Monitors LanguageContext. When language changes to non-English, traverses DOM text nodes and calls /api/translate to translate visible text. Skips elements with data-no-translate attribute (e.g. the language selector itself). Loads appropriate Google Font for the target script.

MiniRichEditor — src/app/admin/MiniRichEditor.tsx

Inline rich text editor widget (67 KB). Used within the admin PostEditor for individual field editing. Supports: bold, italic, underline, headings H1–H3, ordered/unordered lists, blockquote, code block, image insertion, link insertion, horizontal rule, undo/redo.

API Routes Reference

Public APIs

GET /api/search?q={query}
Returns up to 10 disease name/slug/categories matches. Searches name and categories fields case-insensitively. Used by SearchBar autocomplete.
POST /api/track
Body: {path, referrer, userAgent}. Resolves IP from headers, performs geolocation lookup, stores tracking record in tracker collection.
GET /api/translate?text={text}&target={lang}
Proxies translation request to Google Translate API. Returns translated text string.
GET /api/feedback POST
GET: Returns all approved comments with nested replies. POST body: {name, message, parentId?}. Creates new comment or reply. Returns created document.
GET /api/donation-settings
Returns donation configuration document (UPI ID, bank details, QR code). Public endpoint.

Admin APIs (require auth cookie)

POST /api/admin/login
Body: {username, password}. Validates against env vars. Sets HTTP-only session cookie on success. Returns 401 on failure.
POST /api/admin/logout
Clears session cookie. Returns 200.
GET /api/admin/stats?period={1d|7d|monthly|half-yearly|yearly} DELETE
GET: Returns summary KPIs, daily view chart data, top pages, top countries, top regions, recent 50 visitor logs, system health. DELETE: Clears all tracker records from MongoDB.
GET /api/admin/posts POST PUT DELETE
Full CRUD for blog posts collection. GET with ?id= returns single post. DELETE with ?id= removes post.
GET /api/admin/content POST PUT DELETE
CRUD for diseases, categories, library items. Query param ?collection=diseases|categories|library selects target.
POST /api/admin/upload
Accepts multipart form file. Stores and returns CDN/public URL for use in content editor.
GET /api/admin/donation-settings PUT
GET returns full donation config. PUT updates donation config document in MongoDB.
